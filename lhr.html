Longhorn Racing

Simulation and data work for UT Austin’s Formula SAE combustion team.

My work

With Longhorn Racing Combustion, I work on simulations and the data that goes into them. We use lap-time studies to compare changes to the car before committing to a design or setup.

Limited-slip differential model on GitHub ↗

Lap-time simulation

The figure varies drag coefficient and added vehicle mass, then compares the simulated lap times. Aerodynamic changes can improve cornering, but they also introduce drag and weight.

In some of the cases we tested, the added mass cost more lap time than the aerodynamic changes saved.

Data processing

Alongside the lap-time studies, I wrote code to clean and interpolate shock-dyno force–velocity data for our simulations. I also worked on parsing Haltech ECU logs to make the engine data easier for the team to inspect and analyze. My "big" project has been developing a data ingestion and validation pipeline that centers around a RasberryPi which collects data from the 20+ sensors onboard the racecar, and pushes to a cloud-hosted database that various Grafana dashboards and analysis scripts poll from.
