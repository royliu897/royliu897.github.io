Engineering / Longhorn Racing

What makes a lap faster?

Simulation and data work for UT Austin’s Formula SAE combustion team.

The question

A design change can help in one part of a lap and cost time in another. My work with Longhorn Racing Combustion uses simulation and data to help the team compare those tradeoffs.

Limited-slip differential model on GitHub ↗

The lap-time study

The figure varies drag coefficient and added vehicle mass, then compares the simulated lap times. Aerodynamic changes can improve cornering, but they also introduce drag and weight.

Under some of the event assumptions we tested, the mass penalty was large enough that reducing weight mattered more than a more aggressive aerodynamic package. That result depends on the setup and event being modeled.

Making the data usable

I wrote code to clean and interpolate shock-dyno force–velocity data for use in vehicle simulations. I also worked on parsing and organizing Haltech logs so the team could inspect and reuse engine data.

Python · pandas · NumPy · Matplotlib · Julia · SQL
