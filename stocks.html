Independent project / Machine learning

Stock Modeling

Feature engineering, decision trees, and a paper-trading pipeline.

The project

I started this project to see how far I could get with short-term stock prediction. It involved collecting and cleaning data, identifying and building features, experimenting with different model architectures, optimizing hyperparameters, and after many iterations connecting to a paper-trading account.

View the project on GitHub ↗

Models

I tried linear models, random forests, SVMs, convolutional networks, and boosted trees. The SVMs and convolutional networks tended to overfit the data I had. Tree-based models were more useful, so that’s where I focused the rest of the project.

I used random forest feature and permutation importance to figure out which features were actually useful. I then used those features with XGBoost, which I found gave me better predictive performance. Finally, I fine-tuned the XGBoost model using randomized search to explore the global hyperparameter space and a denser grid search for the best-performing regions.

Data and paper trading

I collected price bars, computed indicators, and stored larger training tables in Parquet, with CSV files for debugging and manual verification. I connected the pipeline to Alpaca’s API to test paper-trading execution and live performance.

The screenshot is from a paper-trading run. I didn’t use the project to trade real money.
