Independent project / Machine learning

Testing short-term market signals

Feature engineering, boosted trees, and a paper-trading pipeline.

The experiment

I started this project to see whether I could model short-term price movement with a workflow I could inspect and understand. It became an exercise in collecting data, choosing features, comparing models, and testing the pipeline.

View the project on GitHub ↗

Choosing a model

I tried linear baselines, random forests, SVMs, convolutional networks, and boosted trees. The CNN and SVM experiments tended to overfit the data I had. Tree-based models gave me a more useful direction.

I used random forests to check features, then moved to XGBoost. Repeated cross-validation and parameter searches helped narrow the configuration instead of relying on a single split.

The pipeline

I collected price bars, computed indicators, and stored larger training tables in Parquet, with CSV files for debugging. I connected the pipeline to Alpaca’s API to test paper-trading execution.

The screenshot shows simulated trading activity. I used this to test the live pipeline’s mechanics; the project did not trade real funds.

Tools

Python · pandas · NumPy · scikit-learn · XGBoost · Alpaca API · Parquet
