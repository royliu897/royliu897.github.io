# Unmapped source data and mapping registry

Implemented October 29, 2026. The standalone report now has an **Unmapped** tab immediately after Key Ratios. It uses the existing company load and performs no extra network requests.

The table displays qualified raw tags as row headers, reported units, period type, and source values. Clicking a tag expands its source-native label and definition. Clicking a value opens its SEC filing. Filtering, monetary/share display scaling, annual/quarterly selection, year order and range, and JSON export are available. Raw signs are preserved; the table does not split-adjust values, reconstruct quarters, or calculate TTM. Quarterly, cumulative YTD, annual-duration, and instant observations remain separate rows. Conflicting same-filing observations are flagged rather than silently selected.

The existing explicit tag-to-report registry is now versioned and exposes an inspectable rule index. Its references point to FASB/IFRS taxonomies and the SEC feed documentation. A taxonomy catalog defines source concepts; it does not supply a universal mapping to our report layout. Existing mappings have not all been independently re-audited in this change.

The tab inventories unregistered numeric concepts at report period ends in the **loaded feed**. It includes footnote facts and overlapping totals. An unmapped tag's amount might already be included indirectly in a mapped total or residual Other row. Custom tags and dimensions absent from CompanyFacts and not captured by the selective filing fallback remain outside this inventory. Thus neither the tag count nor an empty inventory establishes completeness.

AI mapping is not implemented or connected in this pass. Source facts, definitions, units, dates, and filing links can be exported for a future mapping assistant. Suggestions should record a target, source evidence, unit/period/class restrictions, sign handling, aggregation and exclusion rules, plus validation. They should not silently mutate the active registry based on a similar name.

## Sweep

The requested agent attempted 12 tickers, with 10 annual-anchored issuers yielding 1,046 distinct qualified unregistered tags. Most are supplemental facts. See [sweep findings](unmapped-tag-sweep.md) and the machine-readable results generated by the sweep script.

High-value candidates are retained for explicit scope-aware rules rather than blind aliases:

- `DepreciationAndAmortization`: verified in the primary cash-flow statements of Visa, McDonald's and UnitedHealth; its taxonomy definition is scoped to nonproduction, so statement context matters before treating it universally as complete D&A.
- `CostsAndExpenses`: includes cost of sales as well as operating expenses; not an unconditional operating-expense synonym.
- `PaymentsToAcquireProductiveAssets`: can include software/intangibles; not equivalent to PPE-only capex.
- `GeneralAndAdministrativeExpense`: may be only one component of combined SG&A.
- Direct Other cash flows: avoid counting them alongside a residual containing the same amount.

No new numeric aliases were activated during this pass. Visa gross profit remains blank. XOM's current/predecessor CIK linkage and BOBS's absent annual anchor are documented separately from mapping gaps.

## Validation

Nine relevant test files pass, including audit tests for cutoffs, annual versus YTD duration separation, namespace collisions, raw signs and zeros, source links, conflicts, and the absence of invented gross profit. The browser was checked for navigation, filtering, source definitions, annual/quarterly switching and display styling. The underlying statement templates remain unchanged.
